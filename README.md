# RawCurveEditor (Android)

Sony `.ARW` を含む各種カメラのRAW画像および通常画像（JPG / PNG）を **LibRaw (C++ / NDK 16-bit パイプライン)** で現像し、**マスター(RGB) + R / G / B 個別チャンネルのトーンカーブ**で色調整を行い、**任意の解像度（%指定・100%超の拡大出力対応・リアルタイムpx表示）** で書き出しができるダークモノトーンUIのAndroidアプリです。

## 主な機能

1. **LibRaw 16-bit ネイティブRAW現像 (`native-lib.cpp`)**
   - CMake の `FetchContent` により `LibRaw (0.21.2)` をソースからスタティックビルド。
   - ソニーの `.ARW` をはじめ `.CR2`, `.NEF`, `.DNG`, `.RAF`, `.RW2`, `.ORF` 等のRAWファイルおよび `.JPG`, `.PNG` を **各チャンネル16-bit (0〜65535)** の内部パイプラインで処理します。
2. **RGB 4チャンネル・トーンカーブ & リアルタイム4色ヒストグラム (`CurveSplineEngine.kt`, `RgbCurvePad.kt`)**
   - `RGB (Master)`, `R`, `G`, `B` の4チャンネル独立編集。
   - タッチした位置に即座にコントロールポイントを打ち、そのままドラッグで滑らかに移動可能。
   - 背景には編集後の色レベルをリアルタイム集計した4チャンネル（RGB統合 + R/G/B）のヒストグラムを表示。
   - 65,536段階（16-bit精度）の合成LUTとC++マルチスレッド処理により、バンディング（階調飛び）のない高速プレビューを実現。
3. **複数画像の同時読み込み・コピー＆ペースト・一括適用**
   - 複数のRAW/画像ファイルを同時に開き、上部フィルムストリップで瞬時に切り替え可能。
   - 編集したカーブのコピー（`COPY`）、他の画像への貼り付け（`PASTE`）、開いている全画像への一括適用（`APPLY ALL`）に対応。
4. **任意解像度（%）・フォーマット指定・一括書き出し (`ExportDialog.kt`)**
   - **JPEG（品質 10%〜100% 指定）** / **PNG** の選択。
   - **解像度スケール（%）**: スライダー（10%〜200%）、プリセットボタン（`25%`〜`200%`）、および直接数値入力（最大300%）に対応し、出力される **`幅 × 高さ px (MP)`** をリアルタイム表示。
   - 16-bit空間での **Catmull-Rom バイキュービック補間** による高画質リサイズと、プログレスバー付きの単体／全画像一括書き出しに対応。

## ビルド方法

1. Android Studio で本リポジトリを開きます。
2. SDK Manager から **NDK (Side by side) 26.1.10909125** と **CMake 3.22.1** がインストールされていることを確認してください。
3. 初回の Gradle Sync / ビルド時に CMake が自動的に GitHub から `LibRaw` を取得し、ネイティブライブラリ (`librawcurve.so`) をビルドします。
